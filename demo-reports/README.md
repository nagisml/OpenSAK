# Demo reports (temporary)

Output of the two example macros `macros/examples/find_statistics.lua` and
`macros/examples/database_statistics.lua`, for reviewing the statistics, chart
and map functions without running OpenSAK.

They were generated from a synthetic, anonymous database (5,000 made-up caches
across Europe, 2,000 of them found by "DemoCacher") — no real cache, owner or
finder data.

**Remove this folder before merging to beta.**
